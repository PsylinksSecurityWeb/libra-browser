# Contributing

Libra is **source available**, not open source: the license does not allow modifying or redistributing the code without written permission from Psylinks Security Private Limited.

What you are welcome to do:
- Read and audit the code, and report problems (bugs, privacy or security issues).
- Open an issue at https://github.com/PsylinksSecurityWeb/libra-browser/issues with a clear title, your Windows version, Libra version and steps to reproduce.
- Suggest features. Anything you send may be used by Psylinks Security Private Limited.

If you want to contribute code, open an issue first and ask for written permission. Approved contributions follow the rules in the README ("Developer guide").
