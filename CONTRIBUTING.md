# Contributing

Libra Browser is open source under Apache-2.0. Contributions and redistributed modifications must follow the LICENSE and retain the required notices.

What you are welcome to do:
- Read and audit the code, and report problems (bugs, privacy or security issues).
- Open an issue at https://github.com/PsylinksSecurityWeb/libra-browser/issues with a clear title, your Windows version, Libra version and steps to reproduce.
- Suggest features. Anything you send may be used by Psylinks Security Private Limited.

If you want to contribute code, open an issue with a clear description and follow the README developer guide. Contributions are accepted under Apache-2.0 unless a separate written agreement says otherwise.
